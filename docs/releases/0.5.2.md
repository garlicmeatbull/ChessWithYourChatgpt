# Chess Coach 0.5.2

## 설치

Assets의 **ChessCoach-0.5.2.apk**를 Android 휴대폰에서 다운로드해 여세요. 요청 시 브라우저/파일 앱의 ‘알 수 없는 앱 설치’를 허용하세요. GitHub 로그인이나 압축 해제가 필요하지 않습니다. Android 8.1 이상, ARM64 휴대폰을 우선 지원합니다.

개발용 서명 APK입니다. 기존 APK와 서명 키가 다르면 업데이트가 거부될 수 있습니다. 앱 삭제 시 저장 기록과 AI 해설도 삭제되므로 필요한 기보를 먼저 내보내세요. PGN에는 AI 해설과 분석 캐시가 포함되지 않습니다.

## 변경 사항

- 대국 화면의 가로 기보는 유지하고 **기보** 버튼을 추가했습니다. 버튼을 누르면 `수 번호 | 백 | 흑` 형식의 정돈된 기보 목록을 볼 수 있습니다.
- 복기 화면에도 **기보** 버튼을 추가했습니다. 선택한 수를 강조하고 그 주변으로 자동 스크롤하며 수를 눌러 해당 국면으로 이동할 수 있습니다. PGN 복사와 처음 위치 이동도 제공합니다.
- 대국 중 기보에서 선택한 수는 복기 화면에서 확인합니다. 뒤로 가면 진행 중 대국으로 돌아갑니다. 기보 목록을 여는 것만으로 AI를 요청하지 않습니다.
- **AI 수 보기**에서 판과 조언을 함께 바로 표시합니다. 별도로 해설을 펼치지 않아도 되며 추가 AI 요청 없이 받아둔 조언을 사용합니다.

## 소스와 라이선스

**ChessCoach-0.5.2-source.zip**에 Stockfish·NNUE 대응 소스와 기존 Java 의존성 원본을 포함했습니다. `LICENSE`, `THIRD_PARTY_NOTICES.md`, `licenses/`를 확인하세요. APK 재배포 시 대응 소스도 함께 제공하세요. **SHA256SUMS.txt**에 APK와 소스 ZIP의 SHA-256을 제공합니다.
