# Chess Coach 0.6.1 — 설명 곁에서 실시간 시각화

## 설치

**ChessCoach-0.6.1.apk**를 Android 휴대폰에서 받아 여세요. Android 8.1 이상, ARM64 휴대폰을 우선 지원합니다. 필요한 경우 해당 브라우저/파일 앱의 ‘알 수 없는 앱 설치’를 허용하세요.

개발용 서명 APK입니다. 이전 설치와 서명 키가 다르면 업데이트가 거부될 수 있습니다. 앱 삭제 시 대국·AI 해설도 삭제되므로 먼저 필요한 기보를 내보내세요. PGN에는 AI 해설·분석 캐시가 포함되지 않습니다.

## 변경 사항

- 열어 둔 AI 시각화 창에서도 생성되는 설명과 그림이 계속 갱신됩니다.
- AI가 필요한 문단에만 그림을 선택합니다. 해당 설명 바로 아래에 관련 체스판과 보라색 AI 화살표를 표시합니다.
- 시각화용 내부 표기는 코칭·크게 보기·시각화 화면에서 숨기며, 생성 중 미완성 표기도 노출하지 않습니다. 모델은 제공된 엔진 수순의 ID만 선택하고 불법 수순이나 확인되지 않은 그림은 표시하지 않습니다.
- 스크롤 중 화면 변경은 모았다가 움직임이 멎으면 최신 상태를 반영합니다. 스트리밍 갱신을 묶고 동일한 글과 판은 다시 만들지 않습니다. 반복적인 기록 조회와 수순 계산을 줄였습니다.
- 그림을 그리기 위한 별도 AI 요청은 없으며 같은 코칭 응답을 사용합니다. 이전 해설도 계속 읽을 수 있습니다. 새 그림 선택 방식은 새로 요청한 코칭에 적용됩니다.

## 소스와 라이선스

**ChessCoach-0.6.1-source.zip**에 Stockfish·NNUE 대응 소스와 기존 Java 의존성 원본을 포함합니다. `LICENSE`, `THIRD_PARTY_NOTICES.md`, `licenses/`를 확인하세요. APK 재배포 시 대응 소스도 함께 제공하세요. **SHA256SUMS.txt**로 APK와 소스 ZIP의 SHA-256을 확인할 수 있습니다.
