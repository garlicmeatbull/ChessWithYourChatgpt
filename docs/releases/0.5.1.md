# Chess Coach 0.5.1

Stockfish와 대국하면서 AI 코칭을 받고 저장된 대국을 복기하는 네이티브 Android 앱입니다.

## 설치

아래 Assets에서 **ChessCoach-0.5.1.apk**를 다운로드해 Android 휴대폰에서 여세요. 요청 시 해당 브라우저나 파일 앱의 ‘알 수 없는 앱 설치’를 허용하세요. GitHub 로그인이나 Actions ZIP 압축 해제가 필요하지 않습니다.

Android 8.1 이상을 지원하며 ARM64 휴대폰을 우선 지원합니다. 이 APK는 개발용 서명으로 제공됩니다. 이전에 설치한 APK와 서명 키가 다르면 업데이트 설치가 거부될 수 있습니다. 앱을 삭제하면 저장된 대국과 AI 해설도 삭제됩니다. 삭제 전에 필요한 기보를 내보내세요. PGN에는 AI 해설과 분석 캐시가 포함되지 않습니다.

## 변경 사항

- AI 대기 표시를 작은 흰색 삼각형 애니메이션으로 변경하고 첫 글자가 나오면 숨깁니다.
- AI 조언 영역을 누르면 전체 설명을 열며 상세 설명과 AI 시각화의 여백을 개선했습니다.
- 코칭 카드와 버튼을 간결하게 정리하고 이어하기를 대국 카드 안으로 옮겼습니다.
- 추가 AI 호출이나 추론 설정 하향 없이 후속 Stockfish 분석과 AI 요청을 병렬 처리합니다.
- 모델별 속도·설명 깊이 안내를 추가하고 기물 이동 애니메이션의 새 설치 기본값을 ON으로 설정했습니다.

## 소스와 라이선스

Stockfish와 NNUE의 대응 소스 및 기존 Java 의존성 원본은 **ChessCoach-0.5.1-source.zip**에 포함되어 있습니다. 라이선스 안내는 소스의 `LICENSE`, `THIRD_PARTY_NOTICES.md`, `licenses/`를 확인하세요. APK를 재배포할 때 대응 소스도 함께 제공하세요. **SHA256SUMS.txt**로 APK와 대응 소스의 무결성을 확인할 수 있습니다.
